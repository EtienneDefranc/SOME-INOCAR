# Concepto de Operaciones (CONOPS)

`SOME-Concepto-de-Operaciones-v1.3.pdf` es la versión vigente del CONOPS, con los datos de contacto personales tachados. Contiene las técnicas de análisis que dieron origen a los requerimientos:

- **Escenarios operacionales:** cinco de operación y dos de soporte (sección 5.8 y 5.9). De ellos salen las capacidades CO-1 a CO-8 y CS-1 a CS-7.
- **Modelado de características:** modelo de SOME en la notación de FeatureIDE, con sus restricciones y sus configuraciones por fase (sección 7.5).
- **Priorización MoSCoW:** requerimientos preliminares priorizados con el cliente (sección 8).
- **Análisis de alternativas:** almacenamiento, tipo de repositorio de datos y cobertura del lago (apéndice A).

Historial: v1.0 (22/10/2026), v1.1 y v1.2 (27/10/2026) y v1.3 (31/10/2026). Los diagramas de esta carpeta son las figuras del CONOPS.
